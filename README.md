# Starmland 🌌

我的个人网站：自我介绍 + 技能展示，纯静态页面，托管在 GitHub Pages。

## 📁 项目结构

```
Starmland/
├── index.html            # 个人主页（关于我 + 技能）
├── skills.html           # 技能与作品展示
└── assets/css/style.css  # 共享样式（深色星空主题）
```

## ✨ 在线访问

GitHub Pages：`https://marvincmm.github.io/Starmland/`（在 Settings → Pages 中开启）

## 🔧 如何维护

- 在 GitHub 网页上直接点文件右上角铅笔图标即可编辑
- 或本地修改后：`git add . && git commit -m "描述" && git push`
